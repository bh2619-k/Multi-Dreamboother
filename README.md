## Quick Installation

### 1. Create a virtual environment

``` bash
make venv
```

### 2. Activate it

``` bash
source .venv/bin/activate
```

### 3. Install GPU version (CUDA 12.8)

``` bash
make install-gpu
make install-dev
```
For CPU version, instead use `make install-cpu`.

### 4. Verify GPU support

``` bash
make check-gpu
```
